## Known limits and open items

- This running DSH process still resolved the plugin module from the earlier workspace-linked path (loader resolution cache). The profile dependency is the stable tarball, so the next DSH restart loads the profile copy; a restart was not performed in this session.
- The tarball is not byte-reproducible across gzip/zlib builds; only the ZIP pins are cross-platform reproducible.
- Auto-load applies to every newly created agent, including teammates and subagents, which adds the skill body to each agent's request prefix. `autoLoad = false` removes it for agents created afterwards.
- The Settings page was verified through live slot registration, not a screenshot; locale switching was not visually inspected.
- High-risk Agent Teams path (real writer/reviewer/executor with external side effects) remains a future forward test.
