## Not verified / known limits

- The page was checked through live slot registration, not a screenshot; visual rendering and the locale switch were not inspected in a browser.
- Installation happened in a running session; a fresh page load (or app restart) was not separately exercised. Replacing an installed package requires a restart to load a fresh JS module generation.
- The high-risk Agent Teams path (real writer/reviewer/executor with external side effects) remains a future forward test; v0.1.0 verifies registration, packaging, and the read-only page.
- Agent Teams is experimental; `maxMembers`, tool schemas, and composition can change between DSH releases.
- The skill is a protocol, not an enforcement layer: write scopes are advisory and reviewer read-only is a protocol rule.
